# Japanese Speaking Cheat Sheet (JLPT N5–N4)

> **Goal:** Activate spoken Japanese quickly by mastering the most common sentence patterns.

---

# Japanese Tenses

Unlike English, Japanese has only **two grammatical tenses**:

- **Non-past** (Present + Future)
- **Past**

Time expressions determine whether something is present or future.

Example:

- 食べます = I eat / I will eat
- 行きます = I go / I will go

---

# 1. Present Simple

### Pattern

```
Verbます
```

### Examples

- 食べます → I eat
- 勉強します → I study
- 働きます → I work

---

# 2. Present Continuous

### Pattern

```
Verbて + います
```

### Examples

- 食べています → I am eating
- 勉強しています → I am studying
- 寝ています → I am sleeping

---

# 3. Habitual Actions

Uses the normal present tense.

### Example

毎週寿司を食べます。

> I eat sushi every week.

---

# 4. Future

Japanese uses the same non-past form.

### Examples

明日行きます。

> I will go tomorrow.

来年日本へ行きます。

> I'll go to Japan next year.

---

# 5. Past

### Pattern

```
Verbました
```

### Examples

- 食べました
- 行きました
- 見ました

昨日映画を見ました。

> I watched a movie yesterday.

---

# 6. Past Continuous

### Pattern

```
Verbていました
```

### Example

昨日勉強していました。

> I was studying yesterday.

---

# 7. Present Perfect

Usually expressed with **もう**.

### Pattern

```
もう + Verbました
```

### Example

もう食べました。

> I have already eaten.

---

# 8. Past Perfect

No direct equivalent.

Usually expressed by context.

### Examples

食べたあとで…

> After I had eaten...

---

# 9. Future Continuous

Usually uses **ています** with a future time.

### Example

明日のこの時間は勉強しています。

> I'll be studying at this time tomorrow.

---

# 10. Future Perfect

Usually

```
〜終わっています
```

### Example

８時までに終わっています。

> I will have finished by 8.

---

# Must / Have To

## Formal

```
〜なければならない
```

Example

行かなければならない。

> I must go.

---

## Common

```
〜なくてはいけない
```

Example

勉強しなくてはいけない。

> I have to study.

---

## Casual

```
〜ないと
```

Example

帰らないと。

> I've gotta go.

---

# Should

### Pattern

```
〜ほうがいい
```

Examples

早く寝たほうがいい。

> You should sleep early.

行かないほうがいい。

> You shouldn't go.

---

# Ought To

### Pattern

```
〜べき
```

行くべきです。

> You ought to go.

# May (Permission)

### Pattern

```
〜てもいい
```

Examples

食べてもいいです。

> You may eat.

> May I come in?

# If

## と

General truths

春になると暖かい。

> When spring comes, it becomes warm.

---

## たら

"If / When"

暇だったら来て。

> Come if you're free.

---

## なら

"If that's the case"

日本へ行くなら京都がおすすめ。

> If you're going to Japan, Kyoto is recommended.

---

## ば

Conditional

時間があれば行きます。

> If I have time, I'll go.

# Daily Speaking Formula

Build sentences using this simple formula:

```
[Time] + [Topic] + [Object] + [Grammar Pattern] + [Verb]
```

Examples:

今日は寿司を食べたい。

> I want to eat sushi today.

明日友達と映画を見ます。

> I'll watch a movie with my friend tomorrow.

日本へ行ったことがあります。

> I have been to Japan.

雨かもしれないから傘を持っていきます。

> It might rain, so I'll take an umbrella.

疲れたので早く寝ます。

> I'm tired, so I'll sleep early.
