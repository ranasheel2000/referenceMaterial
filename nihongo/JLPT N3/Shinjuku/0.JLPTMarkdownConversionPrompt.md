JLPT Markdown Conversion Prompt
Objective

Convert the provided JLPT N3 study material into a polished, well-structured Markdown lesson that matches the formatting and style of my existing study notes.

The output should be one complete Markdown (.md) document that is ready to save directly into my GitHub repository.

General Rules
Produce one complete Markdown (.md) document.
Preserve all important information from the source material.
Rewrite explanations where necessary to improve readability, but never lose meaning.
Correct grammar, formatting, spacing, OCR mistakes, and inconsistent punctuation.
Keep all Japanese exactly as written (including furigana if provided).
Use natural, concise English explanations.
Put every English translation in italics.
Use horizontal separators (---) between major sections.
Use proper Markdown headings.
Keep formatting consistent throughout the document.
Do not wrap the output inside Markdown code fences (```).
Do not include any commentary outside the Markdown document.
