# Japanese Tenses

Unlike English, Japanese has only **two grammatical tenses**.

- Non-past (Present + Future)
- Past

Time expressions determine whether a sentence refers to the present or the future.

Example

食べます
- I eat.
- I will eat.

---

# Present / Future

## Pattern

```
Verbます
```

Examples

行きます
食べます
見ます
勉強します

---

# Past

## Pattern

```
Verbました
```

Examples

行きました
食べました
見ました

---

# Negative

## Present

```
〜ません
```

Example

行きません

---

## Past

```
〜ませんでした
```

Example

食べませんでした

---

# Progressive

## Pattern

```
〜ています
```

Examples

食べています
勉強しています

Meaning

- am doing
- is doing
- are doing

Sometimes

- lives
- works
- wears

---

# Past Progressive

```
〜ていました
```

Example

昨日勉強していました。

---

# Present Perfect

Usually

```
もう + Past
```

Example

もう食べました。

Already ate.

---

# Not Yet

```
まだ〜ていない
```

Example

まだ食べていません。

---

# Experience

```
〜たことがある
```

Example

日本へ行ったことがあります。

I've been to Japan.

---

# Never

```
一度も〜ない
```

Example

一度も行ったことがありません。

---

# Future

Uses present tense.

明日行きます。

Next week働きます。

---

# Daily Speaking Patterns

今日は仕事です。

今勉強しています。

昨日映画を見ました。

もう終わりました。

まだ食べていません。

日本へ行ったことがあります。
