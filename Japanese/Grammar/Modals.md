# Japanese Modals

---

# Can

```
〜られる
```

or

```
〜ことができる
```

Example

話せます。

---

# Want To

```
〜たい
```

Example

食べたい。

---

# Want Someone To

```
〜てほしい
```

Example

来てほしい。

---

# Must

```
〜なければならない
```

Example

勉強しなければならない。

---

# Have To

```
〜なくてはいけない
```

Example

仕事へ行かなくてはいけない。

---

# Gotta

```
〜ないと
```

Example

帰らないと。

---

# Should

```
〜ほうがいい
```

Example

早く寝たほうがいい。

---

# Ought To

```
〜べき
```

Example

勉強するべきです。

---

# May / Permission

```
〜てもいい
```

Example

入ってもいいです。

---

# Must Not

```
〜てはいけない
```

Example

ここで写真を撮ってはいけません。

---

# Don't Have To

```
〜なくてもいい
```

Example

今日は来なくてもいい。

---

# Maybe

```
〜かもしれない
```

Example

雨かもしれない。

---

# Probably

```
〜でしょう
```

Example

明日は晴れるでしょう。

---

# Definitely

```
きっと
```

Example

きっとできます。

---

# I Think

```
〜と思う
```

Example

面白いと思います。

---

# Must Be

```
〜に違いない
```

Example

彼は先生に違いない。

---

# Daily Speaking Patterns

行きたいです。

話せます。

帰らないと。

疲れたほうがいい ❌

早く寝たほうがいい ✔

明日は雨かもしれない。
