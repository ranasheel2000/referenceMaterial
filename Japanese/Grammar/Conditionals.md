# Japanese Conditionals

Japanese has four main "if" patterns.

---

# たら

Most common.

"If"

"When"

Example

暇だったら来て。

If you're free, come.

---

# なら

"If that's the case..."

Example

日本へ行くなら京都がおすすめ。

---

# ば

Formal conditional.

Example

時間があれば行きます。

---

# と

Natural consequence.

Example

春になると暖かい。

---

# Even If

```
〜ても
```

Example

雨でも行きます。

---

# Because

```
〜から
```

Example

疲れたから寝ます。

---

# Because (Polite)

```
〜ので
```

Example

雨なので行きません。

---

# But

```
〜けど
```

Example

高いけど買います。

---

# Then

```
それから
```

---

# Before

```
〜前に
```

---

# After

```
〜あとで
```

---

# While

```
〜ながら
```

---

# Without

```
〜ないで
```

---
