# Japanese Auxiliary Verbs

---

# Try Doing

```
〜てみる
```

食べてみる。

---

# Finish Completely

```
〜てしまう
```

食べてしまった。

財布をなくしてしまった。

---

# Start

```
〜始める
```

勉強し始めた。

---

# Finish

```
〜終わる
```

食べ終わった。

---

# Continue

```
〜続ける
```

勉強し続ける。

---

# Become

```
〜になる
```

暑くなった。

---

# Become Able To

```
〜ようになる
```

話せるようになった。

---

# Choose

```
〜にする
```

コーヒーにします。

---

# Looks Like

```
〜そう
```

おいしそう。

雨が降りそう。

---

# Seems

```
〜ようだ
```

元気のようだ。

---

# Apparently

```
〜らしい
```

忙しいらしい。

---

# Too Much

```
〜すぎる
```

食べすぎた。

---

# Easy To

```
〜やすい
```

読みやすい。

---

# Difficult To

```
〜にくい
```

分かりにくい。

---

# Decide To

```
〜ことにする
```

日本へ行くことにした。

---

# Plan To

```
〜つもり
```

勉強するつもりです。

---

# Let Someone

```
〜させる
```

---

# Be Forced To

```
〜させられる
```

---

# Receive Favor

```
〜てもらう
```

---

# Do Favor

```
〜てあげる
```

---

# Someone Does Me Favor

```
〜てくれる
```
