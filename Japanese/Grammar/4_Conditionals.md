# Japanese Conditionals & Linking Patterns

Japanese connects ideas using grammar patterns.

Main conditional patterns:

1. 〜たら
2. 〜なら
3. 〜ば
4. 〜と

Other important speaking connectors:

- because
- but
- before
- after
- while
- without

---

# Quick Reference

| English | Japanese |
|---|---|
| If / When | 〜たら |
| If that is the case | 〜なら |
| If (formal) | 〜ば |
| Whenever / Natural result | 〜と |
| Even if | 〜ても |
| Because | 〜から |
| Because (softer) | 〜ので |
| But | 〜けど |
| Before | 〜前に |
| After | 〜後で |
| While doing | 〜ながら |
| Without doing | 〜ないで |
| When | 〜時 |

---

# 1. 〜たら

Most common conditional.

Meaning:

- If
- When

## Pattern


Verb past + ら



Examples:


暇だったら来て。

If you are free, come.

時間があったら行きます。

If I have time, I will go.



Very common in conversation.

---

# 2. 〜なら

Meaning:

"If that is the case..."

Used when responding to information.

## Pattern


Noun / Plain form + なら



Examples:


日本へ行くなら京都がおすすめです。

If you are going to Japan, Kyoto is recommended.




暇なら電話してください。

If you are free, call me.


---

# 3. 〜ば

Formal conditional.

## Pattern


Verb ば-form



Examples:


時間があれば行きます。

If I have time, I will go.




安ければ買います。

If it is cheap, I will buy it.



Less common in casual conversation than たら.

---

# 4. 〜と

Natural consequence.

Meaning:

Whenever A happens, B naturally happens.

## Pattern


Verb dictionary + と



Examples:


春になると暖かいです。

When spring comes, it becomes warm.




このボタンを押すと、ドアが開きます。

When you press this button, the door opens.



Not normally used for personal decisions.

Wrong:


暇だと映画を見ます ❌


Better:


暇だったら映画を見ます。


---

# 5. Even If

## Pattern


〜ても



Examples:


雨でも行きます。

Even if it rains, I will go.




高くても買います。

Even if it is expensive, I will buy it.


---

# 6. Because

## Pattern


〜から



Meaning:

Because / Since


Examples:


疲れたから寝ます。

I will sleep because I am tired.




雨だから行きません。

I will not go because it is raining.


---

# 7. Because (Softer)

## Pattern


〜ので



Meaning:

Because / Since


Examples:


雨なので行きません。

I will not go because it is raining.



Difference:


から


Direct reason.


ので


Softer and more polite.

---

# 8. But

## Pattern


〜けど



Examples:


高いけど買います。

It is expensive, but I will buy it.




行きたいけど時間がありません。

I want to go, but I don't have time.


---

# 9. Then / After That

## Pattern


それから



Example:


ご飯を食べました。それから映画を見ました。

I ate food. Then I watched a movie.


---

# 10. Before

## Pattern


Verb dictionary + 前に



Examples:


寝る前に歯を磨きます。

I brush my teeth before sleeping.




食べる前に手を洗います。

I wash my hands before eating.


---

# 11. After

## Pattern


Verb past + 後で



Examples:


食べた後で勉強します。

I study after eating.




仕事の後で会います。

I will meet after work.


---

# 12. While Doing

## Pattern


Verb stem + ながら



Examples:


音楽を聞きながら勉強します。

I study while listening to music.




歩きながら話します。

I talk while walking.


---

# 13. Without Doing

## Pattern


Verb ない-form + で



Examples:


朝ご飯を食べないで出ました。

I left without eating breakfast.




何も言わないでください。

Please don't say anything.


---

# 14. When

## Pattern


Verb dictionary + 時


or


Verb past + 時



Examples:


日本へ行く時、カメラを持っていきます。

When I go to Japan, I take a camera.




日本へ行った時、写真を撮りました。

When I went to Japan, I took photos.


---

# Daily Speaking Practice


暇だったら電話してください。

If you are free, please call me.

時間があれば行きます。

If I have time, I will go.

雨でも大丈夫です。

Even if it rains, it is okay.

疲れたので寝ます。

I will sleep because I am tired.

日本へ行くなら京都がおすすめです。

If you go to Japan, Kyoto is recommended.
