# Japanese Sentence Endings

Sentence endings make Japanese sound natural.

They express:

- emotion
- agreement
- uncertainty
- explanation
- emphasis
- politeness

---

# Quick Reference

| Ending | Meaning |
|---|---|
| よ | New information / emphasis |
| ね | Agreement |
| よね | Agreement + emphasis |
| の / んだ | Explanation |
| かな | I wonder |
| か | Question |
| だよ | Casual emphasis |
| でしょう | Probably / right? |
| じゃない？ | Isn't it? |
| なあ | Emotion / thinking aloud |
| かも | Maybe |
| って | Quoting / I heard |
| じゃん | Casual emphasis |
| けど | Soft ending |

---

# 1. よ

Meaning:

- new information
- emphasis

Used when telling someone something.

Example:


今日は休みですよ。

Today is a holiday.

大丈夫ですよ。

It is okay.


---

# 2. ね

Meaning:

- agreement
- seeking confirmation

Example:


暑いですね。

It is hot, isn't it?

きれいですね。

It is beautiful, isn't it?


---

# 3. よね

Meaning:

Agreement + emphasis.

Example:


面白いですよね。

It is interesting, right?

日本語は難しいですよね。

Japanese is difficult, isn't it?


---

# 4. の / んだ

Meaning:

- explanation
- asking for explanation

Very common in conversation.

Examples:


何してるの？

What are you doing?

今日は休みなんです。

Today is a holiday.


Casual:


そうなんだ。

Oh, I see.


---

# 5. かな

Meaning:

"I wonder..."

Expresses uncertainty.

Examples:


大丈夫かな。

I wonder if it is okay.

明日行けるかな。

I wonder if I can go tomorrow.


---

# 6. か

Question marker.

Example:


行きますか？

Are you going?

大丈夫ですか？

Are you okay?


---

# 7. だよ

Casual emphasis.

Example:


大丈夫だよ。

It's okay.

本当だよ。

It's true.


---

# 8. でしょう

Meaning:

- probably
- right?

Examples:


来るでしょう。

He will probably come.


Confirmation:


明日休みでしょう？

Tomorrow is a holiday, right?


---

# 9. じゃない？

Meaning:

"Isn't it?"

Used for casual confirmation.

Examples:


美味しいじゃない？

Isn't it delicious?

簡単じゃない？

Isn't it easy?


---

# 10. なあ

Meaning:

- thinking aloud
- emotion

Examples:


いいなあ。

That's nice.

疲れたなあ。

I'm tired...


---

# 11. かも

Casual form of:


かもしれない


Meaning:

Maybe.

Examples:


雨かも。

Maybe rain.

遅れるかも。

I might be late.


---

# 12. って

Meaning:

- quoting
- "I heard..."

Examples:


田中さん、来ないって。

I heard Tanaka is not coming.

日本は安全だって。

I heard Japan is safe.


---

# 13. じゃん

Casual emphasis.

Meaning:

- isn't it?
- see?

Examples:


簡単じゃん。

It's easy, isn't it?

いいじゃん。

That's good!


---

# 14. けど (Sentence Ending)

A sentence can end with けど to sound softer.

Example:


ちょっとお願いがあるんですけど…

I have a small request...


The speaker leaves the sentence unfinished.

---

# Masculine / Character Endings

These exist but are less important for beginners.

---

# ぞ

Strong masculine emphasis.

Example:


行くぞ！

Let's go!


Common in:
- anime
- dramatic speech

---

# ぜ

Very casual masculine emphasis.

Example:


やるぜ！

I'll do it!


Less common in normal daily conversation.

---

# な

## Meaning 1: Command (Don't do)

Pattern:


Verb dictionary + な


Example:


触るな。

Don't touch.


---

## Meaning 2: Emotion

Example:


いいなあ。

That's nice.
